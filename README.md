# SVGator skills

Claude skills published by SVGator. Each top-level folder is a self-contained skill
(`SKILL.md` + supporting reference files) that can be installed directly into a
Claude Code `.claude/skills/` directory, or is otherwise consumed as documented below.

| Skill | Covers |
|---|---|
| [`svgator-motion-design/`](svgator-motion-design/) | Design, motion, and interactivity craft for authoring standalone SVG assets (icons, logo reveals, loaders, illustrations, explainers, hero loops) through the [SVGator MCP](https://mcp.svgator.com). Also bundled directly into that MCP server, so any client gets the same craft guidance without installing the skill locally. |

More skills will be added here over time.
